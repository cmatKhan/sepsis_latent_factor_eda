R/lib/association.R

generic_association_scan()

Association scan of scores against every metadata field

For every column of meta_df except id_col, tests each column of scores_mat against it: Spearman correlation for numeric fields, Kruskal-Wallis otherwise. Fields with too little signal (all NA, one level, or fewer than 3 aligned samples) are skipped rather than erroring.

Argument Description
scores_mat Samples x components matrix, rownames sample ids.
meta_df Sample metadata data frame.
id_col Sample id column of meta_df.

Returns: Data frame component, field, test, statistic, p_value, padj (padj BH-adjusted across every row returned).

prepare_design()

Build the model data, formulas and contrasts for one dataset

Applies the design’s drop/keep filters and set_na/recode recodings, optionally fixes the group at each subject’s first timepoint (group_at_first_time), coerces and standardizes numeric covariates, makes every other model column a factor (time in time_order), drops samples with a missing model variable (counted per column), and builds the cell factor with make.names()-safe levels.

Argument Description
meta The resolved dataset config (with a design: block).
sample_meta Sample metadata data frame (read_sample_metadata()).
control_factor compute_control_factor() output, or NULL. When given, its scores become the numeric covariate control_factor in both the variance and the dream formulas, and the share of the control probes’ variance it captures is kept as control_factor_fraction.

Returns: List: spec (the design block), platform, data (model data frame, rownames the sample ids), vp_formula, dream_formula, cell_levels (readable cell level -> safe level), contrasts (build_contrasts()), cancor (cancor_pairs()), dropped (data frame of reason and count), n_samples_metadata, n_group_recoded (samples whose group group_at_first_time changed), numeric_centers and numeric_scales (each numeric covariate’s mean and SD, used to standardize it), control_factor_fraction.

build_contrasts()

Contrasts for dream

Time course: for each group (or all samples when there is no group) with at least min_pairs subjects sampled at 2+ of its timepoints, each later timepoint against the group’s first in time_order, plus an omnibus spec (the group’s contrast names, for a joint F-test at ingest). Groups below min_pairs stay in the fit without contrasts. Cross-sectional: the config’s contrasts: ({name: "levelA - levelB"}, readable group levels), else every pairwise group comparison (later level minus earlier).

Argument Description
design_obj prepare_design()’s list (needs spec, data, cell_levels, dream_formula).
min_pairs Minimum subjects with repeated samples per tested group.

Returns: List: table (name, kind, expression, readable), omnibus (name -> contrast names), L (makeContrastsDream() matrix, NULL when there are no contrasts), skipped (groups left without contrasts and why).

cancor_pairs()

Canonical correlations between the design’s variables

variancePartition::canCorPairs() on the model variables (the interaction left out). Warnings are not stored in the value: subject-level variables nested in subject already show as correlation 1 in the matrix, and a stored once-per-session notice (lme4’s “‘subbars’ has moved to reformulas”) made the design value depend on which dataset’s design was built first in the R session. That notice is muffled; other warnings reach the target’s warnings.

Argument Description
spec A design: block.
data The model data frame.

Returns: List: matrix (or NULL on error), error.

compute_control_factor()

Technical factor from the array’s control probes (the control_factor_<dataset> target)

RUVg-style (Risso et al. 2014): the first principal component of the control probes, oriented to follow their mean, used as a per-sample covariate (design control_probes: {covariate: true}) so each gene gets its own coefficient on it. Shifting every probe by a control offset instead over-corrected ANEMONES (its controls move ~2x as much as genes).

Argument Description

Returns: List: factor (named per-sample scores), fraction (control-probe variance it explains), n_probes.
